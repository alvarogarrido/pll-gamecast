# Tokens

Everything on this page is rendered from `@pll/tokens` (`dist/tokens.ts`, generated from the DTCG JSON in
`packages/tokens/src`). It cannot drift: change a token, run `npm run tokens`, and it updates here. The approved
values and the reasoning live in `docs/design-decisions.md`; naming and usage in `packages/tokens/README.md`.

Two layers: **primitives** (`palette.*`, raw values, never used directly in components) and **semantic** tokens
(`color.*`, aliases of primitives, exposed as Tailwind utilities).
